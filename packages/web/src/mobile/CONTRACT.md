# mobile-remote-web

手机远控网页外壳：处理扫码配对链接、已配对电脑列表、窗口选择与断线重连，接入后渲染与 Web 端相同的 `Root`。规则见 [手机远控](../../../../docs/desktop/mobile-remote-spec.md)「手机网页」一节。

不变量：

- 设备私钥与已配对电脑只存本机 localStorage；配对链接的 hash 读取后立即用 `history.replaceState` 清除。
- 配对必须能在页面内完成（PWA / 原生壳的存储与系统浏览器隔离）：输入框接受配对码或配对链接，「扫码」在页面内调摄像头（`QrScanner.tsx`）；摄像头不可用时只提示，配对码输入始终可用。只接受与当前页面同源中继的配对链接。
- 不缓存会话、不排队待发送命令：重连成功后以新的服务重新挂载 `Root`，由 Host 订阅快照恢复投影。
- 需要重新配对的错误（设备未知 / 被移除 / 主机身份不符）不自动重连，并从本机列表移除该电脑。
- 网络类断线按 1s→15s 退避重连；页面回到前台立即重连。
- `platform/webPlatform.ts` 是 Web 与手机共用的唯一平台实现，不另建副本。
- 手机 bootstrap 统一持有可见视口高度和偏移；子外壳继承根高度，触屏输入采用固定 16px 字号，安全区由手机根容器承接。手动缩放时不重排页面。
- `/m/` 构建提供同源安装清单、主屏幕图标与只联网的 Service Worker；不缓存远控或配对内容，普通 Web 构建不启用安装增强。
