# Mermaid 渲染协调

本模块是成功 SVG 模板缓存、同键请求及串行 Mermaid 队列的唯一 owner。缓存只在 renderer 进程内存在，按完整源码与实际配置匹配，受条数与字节预算约束；失败不缓存。

每个可见图表创建轻量 live controller，单项进行中工作之外只保留最新候选；版本与启用状态共同决定结果是否可提交。暂时解析失败不撤掉已有成功图，最终失败由 UI 明确展示并提供源码。

调用方负责实际主题 token/字体、消息围栏完成边界、页面可见性和 UI；本模块不读取会话 store，不改变运行时协议，不持久化消息。实例化 SVG 必须分配不同 namespace，预览也不能复用聊天实例的 ID。
