# 双栏会话导航

Renderer 工作台是布局、Tab 归属、焦点、比例及未提交草稿身份的唯一所有者。
CLI 仍拥有会话、已接受命令、运行队列和权限事实；本模块不发送任何运行命令。

- 只允许一栏或左右两栏，每栏非空；空工作台只存在于初始化前。
- 会话键使用完整 workspace identity 与 sessionId，全工作台唯一。侧栏打开已有会话只聚焦。
- openSession 的显式 side 用于侧栏“在左/右栏打开”，原子提交目标栏与原会话绑定。单栏唯一会话移往新右栏时，在原左栏保留同 scope 的独立草稿；已有两栏移动时仍按空栏合并规则处理，不保留临时占位草稿。
- Tab id 在移动、换栏和首发绑定时稳定。草稿拥有独立 draftId 与项目/分组放置意图。
- newDraft 的 replaceDraftTabId 用于未发送草稿原地改选工作区和项目：保留 Tab/draft 身份、内容指针、栏位和焦点，只修改 scope 与显式传入的归属。目标不存在或已绑定会话时不提交、不另建草稿，返回请求的 Tab id；会话首发后禁止借此变更项目归属。
- Tab 是内部导航绑定，不渲染额外的顶部会话栏。会话视图操作由侧栏右键与右上分栏入口提交；焦点只路由上下文，不画选中边框。右上布局菜单提供后台草稿的切换与关闭，避免无入口的隐藏草稿。
- 侧栏视图操作集中在“分栏”子菜单，一级菜单不平铺全部布局命令；右上只保留一个布局菜单图标。
- 所有操作先原子提交导航，再由 shell 桥接焦点上下文；shell 不能反向覆盖另一栏。
- moveTab 接受单个或一组 Tab，按移除源后的最终索引一次提交并聚焦目标栏；批量输入必须全部有效且无重复，否则不改变状态。关闭分栏将源栏全部 Tab 按原顺序移入另一栏，并以 preserveTargetActive 保留目标栏当前会话；会话绑定、后台 Tab 和草稿身份保持原样。
- 关闭只改布局；最后一页关闭后创建原 scope 的独立草稿，不停止或删除 runtime 会话。
- 恢复仅恢复导航与草稿指针，不发送消息。旧 pane/group 迁移只消费一次，调用方同时清空旧 owner。
- 远端断连不等于会话删除；只有恢复守卫得到该 scope 的权威存在性结果后才能关闭已删 Tab。恢复存在性确认复用 bindSession 的同会话绑定，不更改身份或发送输入。
- refreshWorkspaceScope 按完整 identity 精确更新同工作区全部 Tab 的连接 scope；本地只按无 identity 的路径匹配。SSH endpoint 换代保留 Tab/草稿/session id，不按路径匹配其他 Source，也不以缺省 endpoint 清除已知连接。

产品规则及验收见 `docs/chat/two-column-workbench.md`。UI 经公开入口消费 store；
会话视图通过既有 per-pane provider 与连接 registry 访问各自 scope。
