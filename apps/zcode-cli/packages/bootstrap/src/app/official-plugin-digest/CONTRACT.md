# cli-official-plugin-digest

文件系统来源内置插件的逐文件摘要缓存。目的：建会话 app 时不再同步重读并哈希全部内置插件文件（1.0.5：插件阶段 p50 0.8s，约 42MB / 600 文件）。规则见 [plugin-compat](../../../../../docs/design/v2/plugin-compat.md)「内置插件摘要缓存」。

不变量：

- 内置插件随应用版本不可变：同一进程同一（应用版本、根目录、插件名/版本）只计算一次。
- 跨进程复用以文件统计签名（文件数、总字节、最大 mtime、逐文件 path/size/mtime/mode 摘要）为准；签名不符或文件损坏一律重新哈希。
- 复制进官方缓存时仍由 seed 逐文件校验 SHA-256；本模块不改变 SEA 来源与非内置插件的完整性语义。
- 持久化写入先合并磁盘最新内容再原子替换，失败只记 warn；条目数有上限。

```text
listFiles(stat) → 签名 → 内存命中 / 持久化命中 → 摘要
                        └─ 未命中 → hashFile(读内容) → 写持久化 → 摘要
```
