# 桌面构建中的官方能力退出

当前独立桌面 Coding Harness 不装配官方遥测、ARMS 或自动更新服务。完整边界见 [独立桌面规格](./standalone-coding-harness-spec.md)。

- 构建不再读取私有商业能力默认值，不通过环境变量恢复官方上报或更新服务。
- 预览包与正式包仍可区分应用身份、图标和数据目录；包身份不恢复账号、套餐、遥测或更新能力。
- 桌面、Agent、Server 与 SSH 部署使用本仓库构建产物。需要更换桌面版本时，手动安装兼容构建。
- 旧设置与历史字段按兼容规则保留，不因此读取官方凭据或发起更新请求。

验证需覆盖启动、空闲与普通 coding 的业务请求用途；用户主动配置的普通模型 API 及扩展网络行为遵循各自配置，不按模型厂商域名整体封禁。具体检查结果见 [验证记录](./standalone-coding-harness-validation.md)。
