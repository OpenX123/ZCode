# 手机远控配对浏览器覆盖矩阵

规则来源：[手机远控 spec](../desktop/mobile-remote-spec.md)。本表只登记已定义的页面内配对语义，不扩展原生壳或手机运行 Agent 的范围。

候选脚本：`packages/web/test/e2e/manual-review/pending/mobile-remote-pairing.mjs`。

运行前构建：`pnpm --filter @zcode/web build:mobile`。

运行：`pnpm exec tsx packages/web/test/e2e/manual-review/pending/mobile-remote-pairing.mjs`。

使用真实手机网页生产构建、隔离的真实中继与 Main 网关、真实 Noise 握手。窗口列表为测试数据；停在窗口选择页，不接入业务 Host、不发送模型请求。摄像头使用浏览器 canvas 的 MediaStream；jsQR 路径识别真实生成的二维码，原生 BarcodeDetector 路径注入受控检测结果。

所有用例放在 `manual-review/pending`，浏览器自动通过不等于人工审阅、正式准入或 iOS/Android 真机验收。运行产物写入 `.tmp/mobile-remote-pairing-e2e/`，不保存设备私钥、中继令牌或完整配对链接。

### 本轮移动输入与安装修复记录

- 源码确认原构建缺少 manifest，完整聊天页的固定 16px 输入字号仍依赖未启用的旧紧凑开关。修改前回归检查分别复现：只有可见视口变矮时根高度不变；草稿页的 `29dvh` 留白把发送按钮推离可见区；横屏 230px 可见高度下，12 行草稿使发送按钮底部落到 269px。
- 修复后隔离浏览器候选 28/28 通过；真实桌面接入本地构建 12/12 通过；部署后公网资源、真实 Host 再检查 12/12 通过。两种引擎均覆盖 390px、360px、844px 横屏、键盘模拟及恢复，长草稿在编辑区内滚动。原有设备保留，未发送模型消息。
- 既有页面内配对候选回归 24/24 通过。相关单测 4 个文件 30/30 通过，包含视口订阅与取消、手动缩放、安装构建和 timeline 滚动记忆；`pnpm typecheck` 通过；`pnpm lint` 0 errors / 91 条原有 warnings；架构检查 0 违规。

- 部署前完整归档并校验原网页，保留旧哈希资源，最后原子替换入口；中继容器启动时间未改变。公网入口与构建 SHA-256 均为 `3107b745677254b0fef74769815825864f0363b77e47a8c32af7e2279e3a6597`。
